# Project Name

A simple Python utility collection containing text analysis and mathematical helper functions.


## 📁 Files Included

* **text_analyzer.py**: Functions to process and analyze text data (e.g., counting words, finding frequencies).
* **math_utils.py**: Helper functions for handling mathematical operations and calculations.

## 🚀 Getting Started

### Prerequisites
Make sure you have [Python 3.x](https://python.org) installed on your machine.

### How to Use
You can import these files as modules into your main script:

```python
import math_utils
import text_analyzer

# Example usage
print(math_utils.add(5, 10))
print(text_analyzer.count_words("Hello world!"))
```

## 🛠️ Features

### Text Analyzer
* Word and character counting
* Sentence parsing
* Frequency analysis

### Math Utils
* Basic arithmetic operations
* Advanced algebraic or geometric formulas
* Number formatting helpers
